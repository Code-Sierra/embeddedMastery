// 31.6 — ONE PAGE BEFORE THE INTERVIEW

Cheat Sheet

Complexities, the choices behind them, the parameters you must quote exactly, and the mistakes that cost offers.

60-SECOND REVISION
  • Firmware DSA = fixed memory, bounded time, no recursion, no malloc after init.
  • Big-O ignores constants; on an MCU n is small, so count cycles and bytes for the real n and design for the worst case.
  • Ring buffer: head (producer) / tail (consumer). Full vs empty: count (needs lock), wasted slot (N−1), free-running indices (used = head − tail, N power of two).
  • SPSC lock-free: one writer per index, write data then publish index, volatile/atomic. volatile ≠ atomic.
  • Heap: parent (i−1)/2, children 2i+1, 2i+2. Insert = sift up, pop = sift down, O(log n). Timer deadlines: (int32_t)(a−b) < 0.
  • Lists: pointer-to-pointer or a sentinel kills the head special case. container_of = member address − offsetof.
  • Floyd: slow 1, fast 2; meet ⇒ cycle; reset one to head, step both by 1 ⇒ entry.
  • Open addressing: α ≤ 0.7, power-of-two size needs a mixing hash, delete with tombstone or backward shift.
  • Binary search: half-open [lo,hi), mid = lo + (hi−lo)/2.
  • Sorts: insertion (small/nearly sorted, stable), heap (worst-case bound, in place), merge (stable, O(n) RAM), counting (small key range). Naive quicksort: O(n²) on sorted/all-equal.
  • Pools: free list stored inside free blocks, O(1), no external fragmentation. Bitmap + CTZ finds a free block in 2 cycles. TLSF = O(1) general allocator.
  • strncpy may leave no NUL; strtok is non-reentrant and merges empty fields; atoi cannot report errors.
  • CRC: specify poly, init, reflect, xorout; verify with "123456789". Table = 1 lookup per byte.
  • Running sums must be integers; median filter = sorted window; dedup = sequence window bitmap.

NEVER DO THIS
  • malloc/free in steady state or in an ISR.
  • Recursion whose depth depends on input (parsers, tree walks, quicksort).
  • A shared count updated by both ISR and task without a lock, and believing volatile makes it atomic.
  • % N with a non-power-of-two N in a hot ISR on a part without a divider (Cortex-M0).
  • Deleting from an open-addressing table by writing EMPTY.
  • Identity hash (key & mask) on pointers or structured IDs.
  • mid = (lo + hi) / 2; closed-range binary search with unsigned indices.
  • Naive quicksort (or library qsort) inside a control loop or ISR.
  • Comparing tick counts with a < b.
  • strncpy(dst, src, sizeof dst) without forcing the terminator; strtok in multi-task code; atoi on untrusted input.
  • Float running sums; 16-bit accumulators for sums of 12-bit samples.
  • "CRC-16-CCITT" without stating init, reflection and xorout.
  • 1 << 31 with signed int; x << 32; __builtin_ctz(0).
